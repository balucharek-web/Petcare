# Polityka Bezpieczeństwa (Security Policy)

## Obsługiwane wersje (Supported Versions)

Aktualnie najnowsza wersja aplikacji otrzymuje poprawki bezpieczeństwa.

| Wersja | Wspierana |
| --- | --- |
| 2.34.x | :white_check_mark: |
| < 2.34.0 | :x: |

## Zgłaszanie podatności (Reporting a Vulnerability)

Bezpieczeństwo danych opiekunów i ich pupili jest dla nas priorytetem. 
Jeśli odkryjesz lukę lub podatność bezpieczeństwa w projekcie **PetCare**:

1. **Nie twórz publicznego zgłoszenia (Issue)** na GitHubie.
2. Zgłoś problem za pośrednictwem prywatnego formularza GitHub Security Advisories:
   `https://github.com/balucharek-web/Petcare/security/advisories/new`
   lub wyślij wiadomość bezpośrednio na adres e-mail opiekuna projektu.
3. Prosimy o dołączenie opisu problemu, kroków reprodukcji oraz potencjalnego wpływu.
4. Odpowiedź i wdrożenie łatki nastąpi w najszybszym możliwym terminie.
